Raspberry Pi Experiment No. 4

Automatic Light Control using LDR

Aim Components Connections Working Procedure Code Output

Aim

To automatically control an LED using a Light Dependent Resistor sensor connected to a Raspberry Pi.

About the Experiment

This experiment demonstrates an automatic lighting system using a Raspberry Pi and an LDR module.

The LDR module detects whether the surrounding environment is bright or dark.

The digital output of the LDR module is connected to GPIO17.

The LED is connected to GPIO18.

When darkness is detected, the Raspberry Pi turns the LED ON. When sufficient light is detected, the LED turns OFF.

Working

The Raspberry Pi continuously reads the digital output of the LDR sensor module.

light_status = GPIO.input(LDR_DO)

According to the program, an LDR digital output value of 0 represents darkness.

1 Bright OFF

Procedure

  1. Connect the LDR sensor module to the Raspberry Pi.
  2. Connect the digital output of the LDR module to GPIO17.
  3. Connect the LED to GPIO18 through a current-limiting resistor.
  4. Connect the LED ground to Raspberry Pi GND.
  5. Power ON the Raspberry Pi.
  6. Open the Raspberry Pi terminal.
  7. Create the Experiment 4 Python program.
  8. Run the program.
  9. Expose the LDR sensor to normal light.
  10. Observe that the LED remains OFF when the sensor detects brightness.
  11. Cover the LDR sensor or place it in darkness.
  12. Observe that the LED turns ON.

Python Code

experiment4.py 
import RPi.GPIO as GPIO
import time

LDR_DO = 17
LED = 18

GPIO.setmode(GPIO.BCM)

GPIO.setup(LDR_DO, GPIO.IN)
GPIO.setup(LED, GPIO.OUT)

try:

    while True:

        light_status = GPIO.input(LDR_DO)

        if light_status == 0:

            # Dark
            GPIO.output(LED, GPIO.HIGH)

        else:

            # Bright
            GPIO.output(LED, GPIO.LOW)

        time.sleep(1)

except KeyboardInterrupt:

    GPIO.cleanup()
